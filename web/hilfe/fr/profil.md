# Profil et réglages

Le bouton 👤 dans l'en-tête du menu ouvre votre **profil** avec tous les réglages personnels. « ← Retour » ou la touche retour de l'appareil le ferme.

![Profil](img/profil.jpg)

## Compte {#konto}

Nom, nom d'utilisateur et vos groupes d'intervention. Ici, vous changez votre **photo de profil** et votre **mot de passe** et vous vous **déconnectez**. La déconnexion efface l'état enregistré sur l'appareil. Sous **Apps connectées**, vous voyez les appareils sur lesquels l'app native est connectée avec votre compte et pouvez les déconnecter.

## Alarme {#alarmierung}

- **Disponibilité** : si vous êtes actuellement alarmé (voir ci-dessous).
- **Mode exercice** : pour les types d'intervention qui le prévoient (p. ex. exercices), vous êtes alarmé comme pour une alarme critique.
- Activer ou désactiver les **notifications push** et envoyer un essai.
- **Installer l'app**, si le navigateur le propose.
- **Alarme de test** : choisir le niveau (Critique, Élevé, Normal, Silencieux) et toucher « Alarme de test dans 30 s ». Après 30 secondes, une alarme de ce niveau arrive seulement chez vous, sans intervention. Entre-temps, fermez l'app ou verrouillez l'écran pour voir si le son, « Ne pas déranger » et le push fonctionnent comme souhaité. « Annuler » arrête le test avant.

> Sans push sur l'appareil, l'alarme de test n'arrive que tant que l'app est ouverte. C'est exactement ce que montre le test.

## Absence {#abwesenheit}

Avec **+ Saisir une absence**, vous vous désinscrivez pour une période (vacances, maladie) ou suspendez votre disponibilité. « Jusqu'au » vide signifie jusqu'à nouvel avis. Pendant une absence :

- vous n'êtes pas alarmé (pas de push),
- vous voyez quand même les interventions et pouvez participer volontairement,
- le menu affiche l'avis ⏸.

Vous terminez les absences en cours avec **Terminer**, les absences planifiées, vous les retirez. L'administration peut aussi saisir des absences pour vous.

## Horaires de disponibilité réguliers {#einsatzzeiten}

Sous **Alarme → Horaires de disponibilité réguliers**, vous définissez par jour de la semaine et heure quand vous voulez être alarmé. **+ Saisir une règle** propose deux types :

- **Suspendu régulièrement** : pendant ces heures, vous n'êtes pas alarmé, p. ex. lu–ve 07:00–17:00 pendant le travail.
- **Horaire de disponibilité** : dès que vous avez au moins un horaire de disponibilité, vous n'êtes plus alarmé que pendant ces horaires, p. ex. piquet sa, di 00:00–00:00 (même heure = journée entière).

Si « Jusqu'à » est avant « De », la règle passe minuit ; les heures après minuit comptent pour le jour choisi (ve 20:00–02:00 = vendredi soir jusqu'au samedi 02:00). Les règles agissent comme une absence : pas d'alarme de mobilisation, les interventions en cours restent visibles et vous pouvez rejoindre volontairement. En haut, à la disponibilité, vous voyez si vous êtes actuellement « suspendu régulièrement » ou « hors horaire de disponibilité » et à partir de quand vous serez de nouveau alarmé. Au maximum 20 règles par personne ; l'administration peut aussi les saisir pour vous.

## Calendrier {#kalender}

Le calendrier (carte **Calendrier** dans le menu sans intervention, au-dessus du plan d'exercices, dans le profil près des horaires de disponibilité ou dans l'en-tête de l'administration) montre tout ce qui a une date au même endroit :

- vos absences et horaires de disponibilité réguliers,
- les interventions auxquelles vous avez participé (avec le droit « Statistique », toutes),
- les exercices et interventions planifiés du plan d'exercices ; si l'inscription est ouverte, vous vous y inscrivez ou désinscrivez directement (**Je participe**, **Je ne participe pas**, **Retirer**). Les responsables d'exercice voient toutes les planifications avec date et les ouvrent dans l'administration avec **Ouvrir**,
- les formations qui expirent.

En haut, vous changez de mois (‹ Aujourd'hui ›), basculez entre **Mois** et **Liste** et affichez ou masquez des catégories. Toucher un jour affiche ses entrées. Avec le droit « Gérer les absences », vous choisissez « Toutes les personnes » et voyez les absences et horaires de tous. L'appareil mémorise votre choix.

## Affichage {#anzeige}

- **Langue** : allemand, anglais, français ou italien. « Automatique » prend la langue de l'appareil, sinon la valeur par défaut de l'organisation. Le choix vaut pour votre compte (aussi dans l'administration et pour les notifications push) ; la page se recharge ensuite. Dans l'administration, vous la choisissez dans le menu du compte en haut à droite, à la connexion sous le bouton « Se connecter ».
- **Système de coordonnées** : LV95 (par défaut), LV03, WGS84 décimal ou en degrés/minutes/secondes, ou masquer les coordonnées.
- **App de navigation** pour le bouton 🧭 : Google Maps, Plans d'Apple, Waze ou une autre app.

## Stations de mesure {#messstationen}

Dans la carte **Niveau & débit**, vous composez vos propres stations de mesure (jusqu'à 20). Recherche par cours d'eau ou lieu, ↑ déplace, ✕ retire. Elles apparaissent dans la fenêtre [Stations de mesure](#einsatz/messstationen), aussi sans intervention.

## Radio {#funk}

- **Écoute** : lire immédiatement les nouvelles annonces tant que l'app est ouverte.
- Utilisation du bouton de parole : maintenir, ou toucher pour démarrer et arrêter.

## Assistant IA {#ai}

Pour chaque fonction de l'assistant IA, vous choisissez dans quelle mesure il vous aide : désactivé, **sur demande** (bouton ✨) ou **en accompagnement** (la proposition est prête à l'ouverture). Plus que ce que l'administration permet n'est pas possible.

## Véhicules {#fahrzeuge}

Si les véhicules sont aussi suivis hors des interventions, vous donnez ici votre accord pour que l'app native annonce les balises à proximité. **Scanner les véhicules maintenant** cherche immédiatement les véhicules à proximité et les annonce (voir [Véhicules et balises](#app/beacons)). Avec le droit nécessaire, vous enregistrez ici une nouvelle balise.

## Documents {#dokumente}

La carte **Documents** indique combien d'entrées sont enregistrées hors ligne sur l'appareil et combien de confirmations de lecture sont ouvertes. **Enregistrer hors ligne maintenant** met à jour immédiatement la copie hors ligne, **Mes propositions** montre vos propositions à la rédaction avec leur état. Vous pouvez retirer les propositions ouvertes. Plus sous [Documents](#einsatz/dokumente).

## Formation {#ausbildung}

La carte **Formation** montre vos formations et compétences avec leur validité : valide, expire bientôt, expirée ou manquante (obligatoire). Si c'est permis, vous saisissez vous-même une formation achevée. Ce qui est en suspens est aussi signalé par un avis dans le menu.

## Version {#version}

La carte **Version** montre la version de l'app et du serveur. **Nouveautés** liste les changements des dernières versions. Après une mise à jour, cette liste apparaît une fois d'elle-même.
